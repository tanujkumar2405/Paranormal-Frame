## 🎨 DESIGN SYSTEM OVERHAUL

### COLOR PALETTE - Muted & Professional
```
Primary Background:  #0a0d12  (deep black)
Secondary Layer:     #111827  (dark slate)
Tertiary Layer:      #1f2937  (muted dark gray)

Primary Text:        #e5e7eb  (soft white)
Secondary Text:      #9ca3af  (muted gray)
Muted Text:          #6b7280  (dark gray)

Accents (hover ONLY):
  Steel Gray:        #6b7280
  Deep Cyan:         #4b9dc4
  Cyan Hover:        #5fadd6
```

**KEY PRINCIPLE:** No bright colors, no neon. Dark, muted, intelligent.

### TYPOGRAPHY - System Fonts Only
```
Font Family: -apple-system, BlinkMacSystemFont, "Segoe UI", "Roboto", sans-serif
NO Google Fonts
NO Playful Typefaces

Headings:
  h1: 3.5rem, UPPERCASE, 3px letter-spacing, bold
  h2: 2rem, UPPERCASE, 1.5px letter-spacing, bold
  h3: 1.3rem, UPPERCASE, 1px letter-spacing, bold

Body Text:
  Size: 16px base (calm, restrained)
  Line Height: 1.7 (generous breathing)
  Max Width: 65 characters (readability focus)
```

**KEY PRINCIPLE:** Serious, controlled, no playfulness.

### SPACING - Maximum Breathing Room
```
Extra Large:    96px (between major sections)
Large:          64px (section padding)
Medium-Large:   40px (element padding)
Medium:         24px (standard spacing)
Small:          16px (component spacing)
Tiny:           8px (micro spacing)
```

**KEY PRINCIPLE:** Large negative space = sophistication.

### ANIMATIONS - Extremely Subtle
```
Only opacity + translateY (NO scaling, bouncing, or fancy effects)

Animation Speeds:
  Fast: 200ms ease-in-out (interactions)
  Normal: 600ms ease-out (subtle transitions)
  Slow: 1000ms ease-out (entrance animations)
```

**KEY PRINCIPLE:** Slow, quiet, professional. Never flashy.

### BORDERS & SHADOWS - Minimal
```
Borders: rgba(255, 255, 255, 0.08) - almost invisible
Light Borders: rgba(255, 255, 255, 0.04) - extremely subtle

Shadows (drop only):
  Small:  0 1px 2px rgba(0,0,0,0.25)
  Medium: 0 2px 4px rgba(0,0,0,0.3)
  Large:  0 4px 8px rgba(0,0,0,0.35)

NO box-shadows. NO glows. NO neon effects.
```
