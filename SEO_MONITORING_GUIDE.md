## 📊 KEY METRICS TO MONITOR

### Google Search Console (Weekly Check)
```
Dashboard URL: https://search.google.com/search-console/
Key Metrics:
- Total Impressions (Target: Growing 5-10% weekly)
- Total Clicks (Target: Growing 5-10% weekly)
- Average Position (Target: Improving month-over-month)
- Click-through Rate (CTR) (Target: 3-5% for brand keywords)
- Mobile Usability (Target: No errors)
- Coverage (Target: 7 pages indexed, no errors)
```

### Core Web Vitals Monitoring
```
LCP (Largest Contentful Paint)
- Good: < 2.5 seconds
- Needs Improvement: 2.5 - 4.0 seconds
- Poor: > 4.0 seconds
- Current Optimization: Font-display swap, lazy-loading

CLS (Cumulative Layout Shift)
- Good: < 0.1
- Needs Improvement: 0.1 - 0.25
- Poor: > 0.25
- Current Optimization: Image dimensions, layout reserves

FID (First Input Delay)
- Good: < 100ms
- Needs Improvement: 100 - 300ms
- Poor: > 300ms
- Current Optimization: Deferred JS, request-idle-callback
```

### Google Analytics 4 (Weekly Review)
```
Key Metrics:
- Organic users (Target: +10% monthly)
- Organic sessions (Target: +10% monthly)
- Average session duration (Target: > 2 minutes)
- Pages per session (Target: > 2.5)
- Bounce rate (Target: < 50%)
- Conversion rate (Target: > 1%)
- Case submissions (Goal completion)
```

## 🚨 CRISIS MANAGEMENT

### If Google Rankings Drop

```
1. Immediate Actions (Same Day):
   □ Check Google Search Console for manual actions
   □ Check for security issues/malware
   □ Verify site accessibility
   □ Check robots.txt and meta robots tags
   □ Verify no unintended redirects

2. Analysis (Next 24 hours):
   □ Compare rankings to previous month
   □ Identify which pages/keywords dropped
   □ Check competitor movement
   □ Analyze backlink profile changes
   □ Review recent content changes

3. Recovery (Next 1-2 weeks):
   □ Identify cause of drop
   □ Fix technical issues
   □ Improve affected content
   □ Check for indexing problems
   □ Resubmit in Search Console

4. Monitoring (Ongoing):
   □ Daily: Check top keywords
   □ Daily: Monitor Core Web Vitals
   □ Weekly: Full GSC review
   □ Document recovery progress
```

### If Core Web Vitals Degrade

```
1. Identify Problem:
   □ Which metric affected? (LCP, CLS, FID)
   □ Check PageSpeed Insights
   □ Review recent changes/updates
   □ Test in multiple browsers

2. Quick Fixes:
   LCP Issues:
   - Enable compression
   - Optimize images
   - Minimize CSS/JS
   - Use CDN
   
   CLS Issues:
   - Add image dimensions
   - Reserve space for ads
   - Avoid layout shifts
   - Use will-change CSS
   
   FID Issues:
   - Defer JS execution
   - Use requestIdleCallback
   - Minimize main thread work
   - Optimize third-party scripts

3. Deploy & Monitor:
   - Implement fixes
   - Test thoroughly
   - Monitor for 1-2 weeks
   - Verify improvement
```
