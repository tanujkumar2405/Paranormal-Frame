## 💡 CUSTOMIZATION GUIDE

### Change Accent Color
```css
:root {
    --accent-cyan: #FF00FF;           /* Your color */
    --accent-cyan-dark: #DD00DD;      /* Dark variant */
    --accent-cyan-light: #FF33FF;     /* Light variant */
}
```

### Adjust Animation Speed
```css
:root {
    --transition-normal: 500ms cubic-bezier(0.4, 0, 0.2, 1);
    /* Change 300ms to your preferred speed */
}
```

### Modify Spacing
```css
:root {
    --spacing-lg: 48px;               /* Increase or decrease */
    /* Affects all major spacing */
}
```
